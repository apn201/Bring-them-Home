# Initial planning and research archive

These documents preserve the initial November 2026 handoff and build plan.
Their working title, starter-pack status, gate assessments and proposed scope
are historical records. Use the [current README](../../README.md) and
[maintained documentation](../README.md) for the present game.

`PACK_SHA256SUMS.txt` is the original handoff's checksum inventory, not a checksum
of the current checkout. Current runtime verification uses `npm run assets:verify`;
release packaging generates a fresh archive checksum and build inventory.

`BUILD_SPEC.md` is the single retained copy of the original specification. The
identical duplicate formerly at the repository root has been removed.
